# Changelog

All notable user-facing changes to CookieGuard are documented here.

The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and the project uses [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-07-19

### Added

- Interactive cookie grabbing through click, tap, drag, and keyboard input.
- Ten shuffled jar defenses with smooth pointer-boundary handling.
- Half-cookie reward after 10 attempts and complete-cookie celebration after 15.
- Generated sound effects with a persistent mute preference.
- Responsive kitchen illustration using CSS and inline SVG.
- Accessible status announcements, progress, focus states, instructions, and reduced-motion behavior.
- Dependency-free GitHub Pages packaging and automated production verification.
