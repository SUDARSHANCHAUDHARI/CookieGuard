# Security Policy

## Supported version

The latest version on the default branch receives security updates.

## Reporting a vulnerability

Please report suspected vulnerabilities privately to `sudarshantechlabs@gmail.com`. Include the affected file or behavior, reproduction steps, and potential impact when possible.

Do not open a public issue for an unpatched vulnerability. Please allow a reasonable amount of time to investigate and prepare a fix before public disclosure.

## Data and dependency posture

CookieGuard has no runtime dependencies, backend, accounts, analytics, or network requests. It stores only the user's sound preference in browser-local storage. The deployed site restricts executable and network-capable content through a Content Security Policy.
